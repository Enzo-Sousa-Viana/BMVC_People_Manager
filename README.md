# BMVC People Manager

Sistema de gerenciamento de pessoas desenvolvido em Python utilizando o framework BMVC.

## Funcionalidades

- Login de usuário.
- Cadastro de pessoas.
- Listagem de pessoas.
- Exclusão de registros.
- API para operações com os dados.

## Tecnologias

- Python
- Bottle
- BMVC
- HTML e CSS
- JSON

## Como executar

1. Instale as dependências:

```bash
pip install -r requirements.txt
```

2. Execute o projeto:

```bash
python3 route.py
```

3. Acesse no navegador:

```text
http://localhost:8080/portal
```
